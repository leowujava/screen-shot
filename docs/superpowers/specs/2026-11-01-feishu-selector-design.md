# 仿飞书截图交互 —— 选区阶段内联标注（设计）

## 意图与背景

现有版本（commit 9f40913）已实现"仿飞书"的选区调整：框选后出现 8 个手柄、可移动、框外暗化（灰点 stipple）、深色工具条（确认/取消 + 尺寸）。但与飞书真实交互相比，关键差距是：**飞书在选区阶段就能直接标注**（箭头/矩形/画笔/文字/马赛克/裁剪），画完才确认；本工具必须先进入独立编辑器窗口。

本次目标：把截图主流程对齐飞书 —— 框选 → 调整 → 直接标注 → 确认（进编辑器精修 / 复制 / 保存）。

## 目标

1. 选区调整模式下，选区下方出现深色工具条：箭头 / 矩形 / 画笔 / 文字 / 马赛克 + 颜色选择 + 粗细 + 撤销 + 确认✓ / 复制 / 保存 / 取消✕。
2. 标注直接绘制在选区图（全屏截图的选区部分）上，选区外保持暗化。
3. 拖动框选过程中：屏幕十字准星 + 选区左上角实时尺寸标签。
4. 框外暗化改为半透明黑色（alpha ≈ 0.5）。
5. 确认后的去向：
   - "✓ 确认" → 标注结果交给现有 Editor（精修、OCR、保存能力保留）
   - "复制" → 标注结果复制到剪贴板，结束
   - "保存" → 存桌面（默认路径），结束
   - "✕ 取消" → 结束，无输出

## 非目标（本次不做）

- 窗口吸附（选区贴合应用窗口边缘）
- 滚轮缩放预览
- 高亮、水印、形状库（飞书还有，但超出核心主流程）
- 录屏、滚动截图
- 右键自定义菜单

## 约束

- Python + tkinter，与现有代码栈一致；全屏覆盖层用 mss 抓的截图做背景。
- 共享 Tk 根窗口架构不变（selector / editor 都是 Toplevel，主循环驱动）。
- Windows 优先（现有代码已大量使用 win32 API）。
- 选区阶段标注的绘制逻辑尽量复用 editor.py 已有函数（mosaic、箭头、矩形、画笔、文字），抽成模块级共享函数，避免两份实现。

## 方案（已选 A）

- **A. 选区阶段内联标注（已选）**：改动集中在 selector.py（标注层 + 工具条），editor.py 抽出共享绘制函数，app.py 调整确认流程。与飞书同构，一次框选即可标注完。
- B. 选区确认后直接进"全屏编辑器"（背景全屏暗化）：selector 不变，但多一次窗口切换，与飞书交互差异大，否。
- C. 只做选区细节增强：用户已排除。

## 已确认的默认决定

1. **裁剪 = 调整选区**：选区阶段的"裁剪"不单独实现，复用已有的手柄缩放/移动能力（与飞书语义一致：裁剪就是缩小选区）。工具条上不放裁剪按钮。
2. **标注撤销**：选区阶段支持撤销（Ctrl+Z + 工具条 ↩），限 10 步，只撤销标注，不影响选区。
3. **文字工具**：点击选区内位置弹输入框（复用编辑器 `_input_text` 模式），输入后以当前颜色绘制。
4. **暗化**：半透明黑色 alpha ≈ 0.5（用 PIL 预渲染 4 块暗化遮罩图贴到画布，替代灰点 stipple）。
5. **十字准星**：框选拖动中，跟随鼠标绘制水平/垂直十字线（画布上的两条线，非光标）。
6. **实时尺寸**：框选拖动中，选区左上角显示 "W x H" 深色小标签。
7. **工具条位置**：选区下方居中；下方放不下放上方（现有 `_tb_show` 逻辑反转）。

## 设计细节

### 数据流

```
Ctrl+Shift+X → capture_fullscreen() → RegionSelector 覆盖层
  → 框选（十字准星 + 实时尺寸）
  → 调整模式（手柄/移动 + 工具条出现）
  → 标注（箭头/矩形/画笔/文字/马赛克，画在选区图上，可撤销）
  → 确认✓ → Editor(标注后的选区图)        ← 现有编辑器，保留精修/OCR/保存
    或 复制 → 剪贴板，结束
    或 保存 → 桌面文件，结束
    或 取消 → 结束
```

### 模块改动

**`drawing.py`（新文件）**：从 editor.py 抽出的共享绘制函数，纯 PIL 操作，不依赖 Tk：
- `draw_arrow(img, start, end, color, width)`
- `draw_rect(img, box, color, width)`（outline 矩形）
- `draw_brush(img, points, color, width)`（折线）
- `draw_text(img, pos, text, color, font_size)`
- `mosaic(img, left, top, right, bottom, block=8)`（从 editor.py 移过来）
- `UndoStack`（从 editor.py 移过来，纯数据结构）

editor.py 改为 `from drawing import *` 再 re-export（`from drawing import mosaic, UndoStack` 形式），保证现有 `test_editor.py` 的 `from editor import UndoStack, mosaic` 继续通过，编辑器行为不变。

**`selector.py`（大改）**：
- 背景：全屏截图 + 4 块半透明暗化遮罩图（PIL 预渲染，随选区变化更新）
- 框选模式：十字准星（两条线）+ 实时尺寸标签
- 调整模式：8 手柄 + 移动（已有）+ 工具条（新）
- 标注层：
  - 选区图 = 全屏截图 crop 出选区（PIL），标注直接画在这张图上
  - 画布上选区区域贴选区图的 PhotoImage（每次标注后更新）
  - 工具选择：brush/rect/arrow/mosaic/text，颜色、粗细、撤销
  - 画笔：拖动连续绘制（与编辑器一致）
  - 矩形/箭头/马赛克：拖拽预览（画布临时元素），松开后画到选区图
  - 文字：点击弹输入框，回车后画到选区图
  - 撤销：维护选区图的 UndoStack（10 步）
- 工具条：选区下方，深色，含：工具组（✏ ▭ ↗ T ▦）| 颜色 | 粗细 | ↩撤销 | ✓确认 | ⧉复制 | 💾保存 | ✕取消
- **标注后重新调整选区**：移动/缩放手柄会使已绘制的标注作废（标注烘焙在旧 crop 上，无法跟随），直接清空标注、从原始全屏截图重新 crop 选区图、清空撤销栈。工具条撤销按钮变灰。这是"简单可预测"的取舍（飞书行为类似：缩放后标注不保留）。
- 结果输出：`on_select(region, annotated_img)` —— 回调**固定两参**。region 为 (left, top, w, h)；annotated_img 为标注后的选区 PIL Image（无标注时 = 原始 crop，仍是 PIL Image）。取消时回调 (None, None)。现有 `app.py` 与测试按两参适配。

**`app.py`（小改）**：
- `process_region_selection(region, annotated_img)`：
  - 复制 annotated_img 到剪贴板
  - Editor(annotated_img) 打开
- 工具条"复制"→ 只复制不打开编辑器；"保存"→ 只保存不打开编辑器
  - 实现：RegionSelector 内部处理"复制/保存"（直接调 capture.py 的函数），"确认"才回调 on_select

**`editor.py`（小改）**：绘制函数改为 import drawing.py，删除本地重复实现。

### 坐标与渲染

- 选区图在画布上的位置 = 选区矩形 (l, t, r, b)（画布坐标），用 `create_image(l, t, anchor="nw")` 贴选区图。
- 标注事件坐标 → 选区图坐标：`x - l, y - t`。
- 暗化遮罩：4 块 PIL 图（黑 + alpha=128），尺寸随选区变化，用 create_image 贴在 4 个角落；选区变化时重建（只在调整/缩放时重建，标注时不动）。
- 性能：全屏背景图只画一次（已有逻辑）；标注时只更新选区图 PhotoImage + 临时预览元素。

### 键盘

- 框选/调整/标注阶段：Esc 取消，Enter = "✓ 确认"（打开编辑器），Ctrl+Z 撤销标注（标注阶段新增）
- 数字键 1-5 选工具（可选，若实现成本低）

### 边界情况

- 选区被缩到无效（< 5px）→ 回退 select 模式，标注层隐藏（已有逻辑，保留）
- 标注后撤销到空 → 选区图恢复为原始 crop
- 文字输入框打开时按 Esc → 只关输入框，不取消选区
- 工具条超出屏幕下边缘 → 放选区上方（沿用现有回退）
- 多显示器：选区图/遮罩/工具条都基于画布坐标，已有 _to_virtual 换算不变

## 风险

- selector.py 变大（预计 ~800 行），工具条 + 标注 + 遮罩三套渲染逻辑要清晰分层。
- 半透明遮罩：tkinter Canvas 的 stipple 替换为 PIL 图后，选区每次变化都要重建 4 张图，需控制重建频率（拖动中每帧重建 4 张小图，尺寸最大为全屏，可接受；若卡可降采样）。
- 工具条是 Toplevel，与选区窗口同 parent，跟随选区移动时避免频繁 deiconify（沿用现有 `_tb_show` 只移动不重建）。
